# Task Tracker

Task Tracker keeps track of all your task for the day. You can mark a task complete by checking the checkbox.

[**Live Demo**](https://virtualnemesis404.github.io/task-tracker/)

## Overview

Task Tracker is a simple to do list built using HTML, CSS and Javascript to demonstrate my understanding of these concepts.

## Technologies Used

- HTML
- CSS
- Javascript

## Features

- Add Task
- Mark tasks as complete
- Delete Task

## Getting Started

### Prerequisites

- Modern Browser
- Git Installed

### Installation 

- Clone the repository

    ```bash
    git clone https://github.com/VirtualNemesis404/task-tracker.git
    ```

- Navigate to project directory

    ```bash
    cd task-tracker
    ```

- Open index.html in the browser
